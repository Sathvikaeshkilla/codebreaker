Code Breaker 🎯
A Java-based number guessing game (Code Breaker) with GUI built using Swing. Inspired by Mastermind, this game challenges players to crack a 4-digit code with feedback after each guess.

🔧 Features
Randomly generated 4-digit secret code
User-friendly GUI using Java Swing
Visual and textual feedback:
C: Correct digit & correct position
W: Correct digit but wrong position
10 attempts limit
Dynamic encouragement messages and image updates
💡 How to Play
Run the program.
Read the instructions in the dialog box.
Enter a 4-digit guess (0–9).
Get feedback after each attempt.
Crack the code within 10 attempts to win!
🧠 Concepts Used
Java AWT and Swing
Random number generation
Arrays and control structures
Event handling (ActionListener, KeyListener)
Basic MVC design pattern
