# Code Breaker 🎯

A Java game built using Swing where players guess a 4-digit secret code.

## 🔧 Features
- 4-digit code guessing game
- Feedback with 'C' (correct position) and 'W' (wrong position)
- Image-based encouragement after each attempt
- 10 attempts to crack the code
- Simple and engaging GUI built with Java Swing
